# Agent 工作流边界设计

## 节点与输入输出

| 节点 | 输入 | 输出 | Milestone |
| --- | --- | --- | --- |
| Material Analyzer | 图片资产 | 商品类别、属性、场景、卖点 | 2 |
| Copy Generator | 商品摘要、平台、brief、检索上下文 | 3 个候选版本 | 2 |
| Content Reviewer | 候选文案、平台规则、品牌规范 | 风险项、等级、建议 | 2 |
| Rewriter | 原文、风险项、商品事实 | 合规版本 | 2 |
| Workflow Orchestrator | 任务与节点 | 阶段事件、最终结果 | 3 |

## 设计原则

1. 节点输入输出使用业务 DTO，不让页面直接依赖模型响应格式。
2. 审核节点必须保留原文片段、风险原因和修改建议，支持结果解释。
3. 改写不能凭空增加商品功效；后续模型接入时要以商品资料和检索证据作为约束。
4. 阶段状态必须可观测：`pending`、`running`、`completed`、`failed`。
