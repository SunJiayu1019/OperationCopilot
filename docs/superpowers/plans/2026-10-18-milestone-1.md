# Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立小红书零食内容运营 MVP 的可运行基础闭环：上传图片、提交任务、查看模拟工作流结果。

**Architecture:** React/Vite 前端调用 FastAPI；后端以内存任务仓储和确定性模拟工作流提供稳定 DTO。模型、RAG、Agent 编排通过文档和服务边界预留到后续里程碑。

**Tech Stack:** React, TypeScript, Vite, FastAPI, Pydantic, pytest, Vitest。

**Spec:** `docs/requirements.md`

## Global Constraints

- 平台固定为小红书，商品类别固定为零食。
- 只实现图片分析、文案生成、内容审核和自动改写主流程。
- 不实现真实平台发布、复杂账号系统、真实模型接入和生产级监控。
- 图片允许 PNG/JPEG/WebP，最大 10 MB。
- 页面必须具备可见表单标签、错误反馈、加载/成功/失败状态。

## Review Focus

- 非法图片类型和超过 10 MB 的图片必须在上传边界被拒绝，并返回可理解错误。
- 空 brief 必须阻止任务创建并保留用户可修正的页面状态。
- 不存在的 task id 必须返回 404，而不是生成空结果。
- 任务结果必须包含四个工作流阶段，避免前端无法解释状态。
- 移动端表单和结果卡片不能依赖横向滚动。
