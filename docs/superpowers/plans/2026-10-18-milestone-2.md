# Milestone 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现本地 MiniMind-V 封装、Qwen 兼容封装、四类知识库的向量检索及独立验证接口。

**Architecture:** FastAPI 的验证接口调用模型适配层或 RAG 服务。视觉层复用项目内 MiniMind-V 权重，非 JSON 视觉描述经 Qwen 结构化；RAG 使用 Markdown 段落切分和字符 n-gram TF-IDF，不引入数据库或 Agent 编排。

**Tech Stack:** Python 3.10+, FastAPI, PyTorch, Transformers 4.57.6, OpenAI SDK, scikit-learn, Pydantic, pytest。

**Spec:** `docs/superpowers/specs/2026-10-18-milestone-2-design.md`

## Global Constraints

- 只处理小红书、零食的 MVP 业务领域；视觉材料可为商品图、详情页截图和竞品素材。
- 模型权重在 `minimind-v/`，不改动第三方源码。
- Qwen 密钥通过 `DASHSCOPE_API_KEY` 提供，不提交到仓库。
- 不实现 ReAct Agent、工具注册、对话页面、平台发布和生产级部署。

## Review Focus

- 缺失本地模型文件时返回配置错误，不回退到模拟数据。
- 模型输出不是 JSON 或字段不全时，返回明确错误；视觉描述可由 Qwen 整理。
- 没有 Qwen 密钥时文本和带命中证据的问答返回 503，检索本身仍可使用。
- 未命中检索的查询返回空证据，不由模型凭空回答。
- 重复索引不会重复堆积知识片段。
