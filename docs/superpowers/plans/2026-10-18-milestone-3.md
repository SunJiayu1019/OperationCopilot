# Milestone 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver bounded ReAct chat orchestration, visible progress and multi-version copy comparison.

**Architecture:** FastAPI process-local background task snapshots wrap five registered tools and a Qwen decision loop. React polls snapshots and renders the conversation and structured outputs.

**Tech Stack:** FastAPI, Pydantic, MiniMind-V, Qwen, TF-IDF, React/Vite, Vitest, pytest.

**Spec:** `docs/superpowers/specs/2026-10-18-milestone-3-design.md`

## Global Constraints

- Xiaohongshu and snacks only; no publishing or account system.
- Keep third-party `minimind-v` untouched and never display credentials.
- No simulated fallback for real Agent results.

## Review Focus

- Unknown or out-of-order model-selected tools terminate safely.
- Missing model credentials report failure, never a fabricated completion.
- Invalid uploaded image fails before loading local weights.
- Repeated frontend submissions cannot corrupt the visible running task.
- Empty retrieval evidence is acknowledged rather than invented.
